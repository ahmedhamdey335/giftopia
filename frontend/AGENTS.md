## This is NOT the Next.js you know

Before changing frontend code, read the relevant guide under `node_modules/next/dist/docs/` and heed its current conventions and deprecation notices.

This app uses Next.js 16 with Cache Components and Partial Prefetching enabled. Page `params` and `searchParams` are Promises. Route prop helpers such as `LayoutProps` and `PageProps` are global and generated by Next.js. Client-side `useSearchParams` needs a `<Suspense>` boundary when prerendered.

<!-- END:nextjs-agent-rules -->

## Project conventions

- Keep all application changes in `src/`; the Laravel backend is a separate project and must not be modified for frontend work.
- Use the shared API client, API error types, token storage, Zustand stores, and `formatEgp`; amounts from the API are integer piasters.
- Use theme tokens and logical Tailwind properties. Keep policy copy in `src/content/policies.ts`.
- Run `npm run lint`, `npx tsc --noEmit`, and focused tests after changes; run the full build before completing a feature batch.
